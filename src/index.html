Lock

Turn a file or folder into one encrypted vault.

Drop a file here, or click to browse

It becomes a single .vaultlock file next to it.

Use a long passphrase you will remember. There is no password reset.

Lost password means lost files. VaultLock cannot recover them, by design.

Unlock

Restore a vault with the password you locked it with.

Drop a .vaultlock file here, or click to browse

The original file or folder is restored next to the vault.

A wrong password restores nothing. Your files stay locked until the right one is entered.

My Vaults

Vaults locked on this device. Passwords are never stored, only locations.

Settings

How VaultLock behaves on this computer.

Right-click menu
Add “Lock with VaultLock” to the right-click menu for files and folders, and “Unlock with VaultLock” for .vaultlock files.

After unlocking

  • The original file or folder is restored next to the vault
  • The vault file itself is deleted once the restore verifies
  • A damaged vault restores nothing, never half a folder

Security

  • AES-256-GCM encryption, a fresh key per file
  • Argon2id key derivation, 64 MiB, 3 passes
  • File names hidden inside the vault
  • SHA-256 integrity check before every restore
  • No backdoor, no recovery, no account
